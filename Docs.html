~/getting-started/install

Loading the library

You build a UI in this order: Window, then Tabs, then Sections, then Elements. Start by loading the file.

From GitHub

Upload Cipher.lua to a repository, open the file, click Raw, and copy that link.

local Cipher = loadstring(game:HttpGet("https://raw.githubusercontent.com/YOUR_NAME/YOUR_REPO/main/Cipher.lua"))()

From your executor's workspace folder

Put Cipher.lua in the executor's workspace folder. This is handy for testing before you upload.

local Cipher = loadstring(readfile("Cipher.lua"))()

Your first hub

local Cipher = loadstring(game:HttpGet("YOUR_RAW_LINK"))()

local Window  = Cipher:CreateWindow({ Title = "My Hub" })
local Tab     = Window:AddTab("Main")
local Section = Tab:AddSection("Player")

Section:AddButton({
    Name = "Say hi",
    Callback = function()
        print("hi")
    end,
})

Window:AddSettingsTab()   -- themes, menu key and configs in one line

~/getting-started/shared-options

Things every element shares

Every element accepts these options and has these methods, so you only learn them once.

OptionWhat it does
NameThe text shown on the element.
DescriptionA smaller grey line under the name.
TooltipText that appears when the mouse rests on the element.
FlagA unique id. The value appears in Cipher.Flags[Flag] and is saved in configs. See flags.
CallbackYour function. It runs when the value changes or the button is clicked.
Lockedtrue or a reason string: the element starts locked and can't be used.
Visiblefalse hides the element at the start.
MethodWhat it does
:SetTitle(text)Changes the element's name.
:SetDescription(text)Changes the description line (only if the element was created with one).
:SetVisible(bool)Hides or shows the element.
:Lock(reason?)Greys out the element and blocks clicks. :Unlock() undoes it.
:OnChanged(fn)Adds an extra listener without replacing Callback.
:Destroy()Removes the element.
Callbacks are error-safe. If your callback errors, the UI keeps working. The error is printed with warn and also appears in the terminal.
Callbacks don't run on creation. A Default value is only displayed. Your callback runs the first time the value changes, including when a config is loaded.
Set(value, true) is silent. Passing true as the second argument updates the element without running your callback.

Your own commands

-- short form
Window:AddCommand("hi", "say hi", function(args, console)
    console:Success("hi " .. (args[1] or "there"))
end)

-- full form
Window:AddCommand({
    Name = "speed",
    Description = "set walkspeed",
    Usage = "speed <number>",
    Aliases = { "ws" },
    Callback = function(args, console, rawLine)
        local n = tonumber(args[1])
        if not n then return "usage: speed <number>" end   -- a returned string is printed
        Cipher.Options.WalkSpeed:Set(n)
        console:Success("walkspeed = " .. n)
    end,
})
  • args is a table of the words after the command name. Quotes group words: say "hello world" gives args[1] = "hello world".
  • console is the terminal. It has the same methods as a Console.
  • Write to the terminal from anywhere with Window:Log("text", "success").

~/systems/configs

Configs (save / load)

Saves every flagged element to <ConfigFolder>/configs/<name>.json. This needs executor file functions (writefile, readfile, isfile, and so on).

Cipher:SaveConfig("legit")                  -- returns true, or false + error
Cipher:LoadConfig("legit")                  -- returns true + count, or false + error
Cipher:DeleteConfig("legit")
local names = Cipher:ListConfigs()          -- { "legit", "rage" }

Cipher:SetAutoload("legit")                 -- mark as autoload
Cipher:LoadAutoloadConfig()                 -- put this at the END of your script

if not Cipher:HasFileSystem() then
    print("this executor can't save files")
end
Loading a config runs the callback of every element whose value changes, so your features switch on. The theme is saved and restored too.

To leave an element out of configs, set Cipher.Options.X.IgnoreConfig = true.

~/reference/faq

Tips and FAQ

Re-running my script creates a duplicate UI.

It shouldn't: a window with the same Title replaces the old one. If you change the title between runs, call Cipher:Unload() first.

How do I turn off my features when the UI is closed?

Window:OnDestroy(function()
    Cipher.Flags.AutoFarm = false   -- make your loops stop
end)

How do I make a feature that works while a key is held?

Use a Keybind with Mode = "Hold". The callback gets true on press and false on release.

How do I update a dropdown after the UI is built?

Dropdown:Refresh({ "new", "options" })

The UI is too big on my screen.

It scales down automatically on small screens. You can also call Window:SetScale(0.8) or use the UI Scale slider in the settings tab.

Does it work on mobile executors?

Yes. Dragging, sliders and color pickers all accept touch, and a floating >_ button toggles the window.

Where does the UI go?

It is parented to gethui() when available, then CoreGui, then PlayerGui as a last resort. It also uses syn.protect_gui when the executor has it.
